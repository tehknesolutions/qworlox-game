# Q'Worlox — Simulation Architecture v0.2

## Purpose

Use the digital runtime as a laboratory for the same Game Core that will govern the physical game.

## Evidence levels

### Level 0 — deterministic engine
Seeded RNG, replayable state transitions and atomic combat resolution.

### Level 1 — geometry
Compare 18 / 36 / 72 route candidates under identical baseline rules.

### Level 2 — territory
Use graph-defined contested regions, center and lane transitions.

### Level 3 — cards
Introduce category-specific card triggers and resource limits.

### Level 4 — archetypes
Introduce Citizen/Cavalier attributes and exclusive-die sources.

### Level 5 — human decisions
Replace baseline automated policies with recorded player choices.

### Level 6 — physical prototype
Validate readability, handling, pacing and actual table behavior.

## Current boundary

The current simulator is a technical integration experiment. Its metrics must not be interpreted as final balance evidence because the full card, territory and human-decision systems are not yet implemented.

## Required reproducibility

Every comparison must document:

- route length;
- seed;
- number of matches;
- ruleset version;
- AI policy version;
- card set version;
- character/stat version.

A result without these identifiers is not a reproducible Q'Worlox experiment.

## Next implementation target

Replace the current positional shortcut in combat-aware simulation with the canonical Board Graph. A simulated encounter must be generated by actual graph occupancy, not inferred from arithmetic position alone.
